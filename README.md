# 進化計算コンペ2026

配布プログラムのGA部分（`ga.cpp`，`const.h`）を改良しました．
コントロール数を8個に固定し，初期集団の工夫と局所探索，GAの2回実行を加えています．

## ビルドと実行

C++17に対応したコンパイラが必要です．`input/` があるこのフォルダで実行してください．

### macOS / Linux

```sh
make
./orienteering
```

`make run` でビルドと実行をまとめて行うこともできます．

### Windows（Visual Studio）

1. 空のプロジェクト（C++）を作成し，`.cpp` 5本と `.h` 5本を追加する
2. プロパティで C++ 言語標準を **ISO C++17**，追加のオプションに **`/utf-8`** を設定する
3. デバッグの作業ディレクトリを `input/` の親フォルダ（このフォルダ）にする
4. `Ctrl + F5` でビルドして実行する

## 出力

実行すると `output/` に `best_course.json`（コース）と `fitness_history.csv`（世代ごとの評価値）が作られます．
